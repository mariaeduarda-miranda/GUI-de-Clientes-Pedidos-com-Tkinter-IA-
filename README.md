# App Tkinter - Clientes e Pedidos

Pequeno sistema desktop com Tkinter + SQLite.

## Estrutura
- db.py: Banco de dados
- models.py: Acesso aos dados
- views/: Telas Tkinter (clientes e pedidos)
- utils.py: Validações e mensagens
- main.py: Ponto de entrada

## Executar
python main.py
